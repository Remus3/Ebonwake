# 0009 - UI/UX audit of the dashboard and overlay (2026-10-06)

Status: research, read-only audit. No app code changed. Follow-up to 0005
(2026-10-05), after plans 019-073 added cards, tabs, overlay contexts and
notification rules.
Scope: `app/dashboard/*`, `app/overlay/*`, `app/shared/*`, `app/main.js`, the
server payloads they render (`server/ew/onboarding.py`, `context.py`,
`signals.py`, `data/*.json`), plans 025, 047-051, 067-073.

Method:
1. Code review of every renderer module, `ewcore.js` view builders
   (`composeNow`, settings groups, overlay context) and the shared CSS.
2. Live check against the running server on the EW port (commit 4649c98,
   one hand-off commit behind HEAD a6bff3c; no route skew). Dashboard opened
   over the HTTP fallback in the built-in browser at the compact content size
   1264x761, at the 960x600 minimum window with a 1.3 zoom (the top of the
   `ui.scale` range), and at 390 px phone width; overlay at 340 px over a
   bright background. Game closed the whole time; no game window touched.
   Card / input counts read from the live DOM. Screenshots not committed.
3. Walk-through of a returning Deadeye's first minute: open EW, decide what
   to do next, act.

Line numbers are against HEAD a6bff3c.

## 1. Headline

0005's big gaps are closed: version-skew pill (020), content-sized grid,
focus-visible, tab roles and badges (047), toasts and OS notifications (026),
overlay placement, halo and ticker (022, 029), palette (050), settings (030),
SSE bus (049). The new problem is sprawl and disagreement, not missing data:

- 9 tabs, 66 cards, 289 form inputs live (Progress alone: 11 cards, 128
  inputs; Settings: 11 groups, 54 inputs).
- Home shows 11 cards; on the test store 7 of them are pure empty states, and
  the one card the operator needs first (What now) is the most truncated
  ("Bulgas...", "Finish 5 ..."). The same fact (boss in 3 min, reset in
  3 min, 5 dailies left) appears in 3-4 cards on the same screen.
- Three surfaces disagree about the same signal: Get started says the
  Documents folder is "Not found", Settings says it is auto-detected and in
  use, Signal health says "no ScreenShot folder yet - take one in game".
  Only the last is right.

## 3. Returning-Deadeye first minute

What the operator needs first, in order: (1) the one thing to do now and how
long they have; (2) what is unfinished before the next reset; (3) is anything
running that costs money (buffs, grind session); (4) is EW itself healthy.

Today: (1) is on Home but truncated (H2) and repeated by three other cards
(H3); (2) is split across What now, Dailies left, Next resets and the Today
badge; (3) is two empty cards when nothing runs (H4); (4) is a green pill plus
a Get started card that contradicts Signal health (H1). Target after 076-078:
Home = What now (full width), Today's open rows, a single Timers card, any
running buff / session card, then one "Quiet:" line - fits 1264x761 with no
scroll and no repeated fact.
