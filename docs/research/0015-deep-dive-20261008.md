### F1 - plan 085 would stay silent on today's notes

Plan 085's seeded hints accept only ASCII `to` / `->` / `=>` between old
and new value (`xp_epochs.json` `cap75-xp-rescale` expect regex;
`xp_buffs.json` hints) and match the raw page text. `patchverify.check_row`
does no Unicode folding (only the evidence line is ASCII-squashed). The
Asia text writes the level change as "70 U+2192 75" and the boon as
"Adventure's Boon". NA notes reuse U+2192 (read 2026-10-08 on 10621: menu
paths "Menu (ESC) U+2192 Adventure (F5)"). If NA copies the Asia wording,
the epoch and the boon preset come out `silent`, not `confirmed`, and the
wrong 62-64 cap band has no hint at all. -> candidate A (plan 087).

### F2 - in-game per-kill EXP is now visible

The Monster Zone Info panel shows per-kill EXP and a recommended level per
zone. EW's level ETA (011 / 018) knows only the observed XP rate, and the
grind recommender (012) only community AP/DP bands plus a coarse
`xp_tier`. With the per-kill cap including buffs, a stacked XP buff adds
nothing once a zone's base kill already reaches the cap (Lv 56+ bands are
tiny). A screenshot of that panel, taken by the operator with the game's
own key, is the allowed OCR input (research 0001 s4). -> candidate B
(plan 088).
