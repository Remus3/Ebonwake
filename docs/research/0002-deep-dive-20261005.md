## 1. Headline: level cap 75 and a combat XP revamp (Global Lab, posted 2026-10-02)

Source: BDFoundry Global Lab summary,
https://www.blackdesertfoundry.com/global-lab-updates-2nd-october-2026/
(posted 2026-10-02, read 2026-10-05). Corroborated by the official Global Lab
notice list https://blackdesert.pearlabyss.com/GlobalLab/en-US/News/Notice
(read 2026-10-05). Global Lab changes usually reach NA/EU live at the next
maintenance (2026-10-08) or the one after; NOT yet live on 2026-10-05.

- Max level 70 -> 75. Levels 70-75 each add +3 monster AP and +3 monster
  damage reduction (+18/+18 at 75; not stacking with a tag partner, who gets
  the higher character's bonus).
- Required combat XP changed for ALL level ranges (no per-level numbers
  published). Monster, quest and Black Spirit XP all rescaled.
- New per-kill XP cap as a share of the current level, buffs included:
  ~20% (Lv 1-5) falling to ~2% (50-55), ~0.2% (56-61), ~0.01% (62+).
- XP buff values: Body Enhancement 50% -> 100%, Adventure Blessing 15% -> 30%,
  Pearl outfit set combat/skill XP 10% -> 50%.
- Main questlines (Calpheon / Morning Light / Mountain of Eternal Winter) each
  reach Lv 56; Rebirth of Darkness from 56 reaches 60; Olvia combat course
  60 -> 61.
- Monster name colours now span 7 steps (<= -3 .. >= +3); out-levelling a
  monster gives +3 monster DR per level up to +9. The game UI will show
  monster level, XP per zone and a recommended level per hunting ground.
- DEADLINE: unclaimed character-switch (tag) XP is deleted at the
  2026-10-07 (KR) / 2026-10-08 (global) maintenance. Operator act: claim it
  before the 2026-10-08 maintenance.
- Combat Secret Books (XP from Black Shrine, Altar of Blood, node war) arrive
  2026-10-15 global, crediting from 2026-10-08.

Impact on EW (measured against the code on 2026-10-05):
- `server/ew/leveling.py` hard-codes `LEVEL_RANGE = (1, 70)`: a level 71-75
  sample would be rejected once the patch is live.
- Plan 011 milestone seed [50, 56, 57, 58, 60, 61] predates the new quest
  ladder and the 70-75 AP/DR bonuses.
- Plan 011 rate/ETA is percent-per-hour, so it survives a changed XP table,
  but rates measured before the patch are not comparable after it.
- Plan 012 `server/ew/data/grind_spots.json` `level_min` values and xp tiers
  were sourced before the revamp and the new level-gap DR rule.
- Plan 005 buff `xp_pct` values typed before the patch (Body Enhancement 50,
  Adventure Blessing 15) become wrong.
-> Plan 018.

## 5. Public data sources and community tools (re-checked 2026-10-05)

- arsha.io v2: unchanged. NEW to EW: since v1.0.4 a WebSocket
  `wss://api.arsha.io/events` publishes {id, region, endpoint} whenever a
  cache entry expires (https://github.com/guy0090/api.arsha.io, read
  2026-10-05). EW could refresh a watched item exactly when arsha has new data
  instead of on its own TTL. Value is low while the operator is leveling
  (ROADMAP ranking note); not planned this round. Reverses if: the Market tab
  becomes a daily driver.
- BDO-REST-API: official instance `https://bdo.hemlo.cc/communityapi/v1`, v0
  dead, v1 current, Docker image updated ~3 months ago
  (https://github.com/man90es/BDO-REST-API, read 2026-10-05). Plan 004 uses
  the base from the upstream openapi `servers[0]`, which differs from this
  README host; both are the same maintainer's project. Recorded only; a
  plan 004 follow-up re-checks the openapi before changing anything.
- Velia Inn developer docs (https://developers.veliainn.com/) document the raw
  publisher market POST endpoints; EW keeps arsha as primary (research 0001).
- Garmoth / BDOlytics / BDO Codex: still no documented public API. A
  third-party "AI companion" on Nexus Mods (Cuda Spirit) claims to pull gear
  from Garmoth and prices from arsha; EW does not scrape Garmoth (research
  0001 section 3 stands).
- Ikusa (built on BDO-REST-API) analyses exported node-war combat logs; not
  relevant to a solo leveling Deadeye.
- patchbot.io aggregates BDO patch notes; a secondary source only - the
  official `/News/` pages are robots-allowed and authoritative.
